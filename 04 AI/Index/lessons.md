# Index (main website): lessons

## 2026-11-25
- To prove a split of a single-file page changed nothing, screenshot old and new in every style with reduced motion on. With motion on, rotating tiles gave false differences.
- After a graduation, check every local link on the home page. Six tiles broke when folders were removed.
- A stone wall in CSS: shared seams between courses give fitted stones. The seam must rise where a joint comes from above and dip where it comes from below; the other way round pinches stones at the waist.
- Plain Voronoi cells with weights for width let wide cells swallow narrow ones; courses with shared seams keep every label its room.
- Test clipped labels with `isPointInPath` on the same path used for `clip-path`.
- When a style is named after a movement, ask for or use a picture of the real object. A colour scheme borrowed from another app was replaced the same day.
- To merge sections in one style only, set the sections and lists to `display: contents` and place the tiles on the page. The HTML stays as it is.
- Look at photos of the real thing before drawing it. Three rounds of "polygonal" hexagons missed that Cusco walls are mostly notched near-rectangles of very uneven size.
- Real notches in a tiling: pack on a grid, move cells between neighbours, then nudge only the shared corners. There can be no gaps.
- A rectangle with four corners notched has exactly 12 corners; keep the side midpoints on straight lines so it still reads as 12.
- In an edit mode over links, stop clicks in the capture phase so other click handlers (the Nursery counter) don't run, and set `touch-action: none` on the pieces.
- Interlock reads from tongues in the middle of a side, not from stepped ends. Finer grid cells and bigger stones leave room for them.
- Decoration meant as realism (bevel lines, corner numbers, knobs) was cut. Show structure with the shapes themselves.
- A button over a clipped tile belongs beside the link, not inside it: the shape would clip it, and its text would change the tile's name.
- Test that a button's invisible tap area does not cover the label, not only its drawn circle.
- Lay out toy pictures with "gravity": give each place a left and right edge and drop the piece onto what is below.
- Before restructuring a page, fetch `origin/main`: other sessions were editing the same file, and their changes had to be ported by hand.
- "Merge main into my branch" is not "merge my branch into main". Check with `git log origin/main` and a file on the live site.
