# Adventure — Lessons

- 2026-10-27: Jimmy prefers AI working in the background (nightly, between turns) over a live AI in the page. It keeps keys out of the browser and gives better, more consistent stories.
- 2026-10-27: Supabase `apply_migration` can stop for a user confirmation in a remote session; if no one answers it times out after 60 s with nothing applied. Check `pg_class` before retrying, and build the rest in the meantime.
- 2026-10-27: For "edit anything, roll back anything", one generic trigger that copies `to_jsonb(old)`/`to_jsonb(new)` into a history table, plus a restore function using `jsonb_populate_record` with `on conflict (id) do update`, covers every table with no per-table code.
- 2026-10-27: In a two-column layout, auto-scrolling a column to the bottom pushed the character buttons out of view. Make the controls sticky and scroll only the new item into view.
- 2026-10-27: World-building tools that scale: places as a tree where every place is the map of its children (boxes in percent), an append-only journal per subject, and planned chapters as rows with a status, so the plot, the storyteller and the player page share one table.
- 2026-10-27: The root `index.html` lists only projects with their own repos; nursery projects need their own section with relative links (`03%20Projects/...`).
- 2026-11-10: A "no-memory" opening suits a game about learning how a child acts: the world reveals itself through choices, and the player's true past is a menu of possibilities the storyteller picks from only once the choices have earned it (storylet style), never fixed up front.
- 2026-11-10: Weave the family's earlier story into a new world instead of replacing it (the Sun and Moon key, Bristle, the Old Lady became Granny Wren, the chest moved to the ruined village). Continuity matters more to a child than a clean slate.
- 2026-11-10: A big world bible needs two copies: full Markdown files in the repo for people and the storyteller, and short `adv_entries` in the database that Jimmy can edit under the hood. The storyteller reads both; the database wins when they disagree.
- 2026-11-10: Generate the seed SQL and the offline JSON from the voiced script, so the long text, the script and the recording can't drift apart. Test the whole SQL chain on a local Postgres (pg 16 is installed in the cloud container; the scratchpad isn't reachable by the postgres user, so use a throwaway `/tmp` folder), with stub `anon`/`authenticated` roles and `auth.uid()`.
- 2026-11-10: Python's `http.server` doesn't answer Range requests, so Chromium can't seek in an MP3 served by it (tap-to-jump looked broken). Test audio seeking with a range-capable server (`npx http-server`); GitHub Pages is fine. Also, seeking before `loadedmetadata` is ignored.
- 2026-11-10: When stopping an `<audio>`, clear its `onerror`/`onended` before clearing `src`, or the old element's error event stops the *next* reading.
