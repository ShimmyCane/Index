## Not yet verified (open)

- **Inclination, node and perihelion** (Ceres 10.59 / 80.39 / 73.60 deg; Haumea 28.19 / 122.17 / 239.04; Makemake 28.96 / 79.31 / 294.84; Eris 44.04 / 35.95 / 151.64) are from memory of the JPL Small-Body Database, not re-checked. The UNLV table gives Makemake's inclination as about 29 deg and Eris's as about 44 deg; Space.com gives Eris as nearly 47 deg. Where sources disagree, the JPL SBDB page is the official one, to check.
- **Mean longitude L** is a placeholder (each body at perihelion on J2000). The search did not give JPL epoch values. The true starting place of each dwarf is not set.
- **Spin periods** (Ceres 0.378 d, Haumea 0.163 d, Makemake 0.951 d, Eris about 1.08 d) are from memory, not re-checked.

Check against the JPL SBDB lookup (https://ssd.jpl.nasa.gov/tools/sbdb_lookup.html) for each object before public use.
