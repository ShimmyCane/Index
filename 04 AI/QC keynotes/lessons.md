# QC keynotes — lessons

- Answers to convo questions come back as inline text against line numbers. Record them in the convo file first, then build.
- A guideline framework that is typed in (not preloaded) needs auto-save and export, or the typed content is lost on reload.
- Favicon requests return 404 in headless tests. An empty `<link rel="icon" href="data:,">` silences them without adding a file.
