# Cheetah Simulator — lessons

## 2026-11-25, planning round
- A brief can contain a fact the sources contradict (here: females stay with Mum). Check it, build to the sources, and say so at the top of the convo.
- Search summaries leave gaps (top speed, the bite). Mark general-knowledge facts ⚑ in the research file so none reaches the screen unchecked.
- A stage list that branches by sex needs one stage per path to be *true*, not symmetrical; the male path has no cub-raising stage, which became a question.

## 2026-11-25, Jimmy's answers (convo v0.1)
- Gentle mode is a setting, on by default. It changes the telling, never the facts; the "How it really is" panel always shows the real thing. Ask Jimmy before any new soft-setting rule.
- Choose the sex up front; random by default, so a child can play with no set-up. Rename and sex toggle are available but never required. Build choices that can be refined later, not forced.
- Cumulative stage clock: target = 10 + 5 × restarts minutes. Read his words as the rule; confirm (convo v0.2 question 7).
- Age-appropriate facts are per mode, not one text for everyone.

## 2026-11-25, series and settings
- Put a series' navigation (Other games) in ⚙️ from the start, with the unbuilt games disabled, so the links work the day each page opens.
- Ask which game is which version before creating folders. My own last message had the bat as V2; the A1 order said gibbon. Asking took one question and avoided a rename.
