# Living Room Scene: Claude pointer

Purpose: build a flat scene from a living-room photo, over 10 versions (V1–V10), comparing each render with the photo.

- Design: `schematic.md` (this folder)
- Questions and decisions: `convo/`
- Renders: `renders/` (Chromium PNG of each version)
- AI notes: `04 AI/Living Room Scene/brief.md` and `lessons.md`

How to run: open `living_room_v#.html` in any browser. To render, use Playwright with the pre-installed Chromium (see the render script in the session scratchpad).

Do not commit the source photo. Only the drawn version goes into the repo.
