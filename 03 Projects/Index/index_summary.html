Home page: code summary

Main file: index.html at the repo root. Made 2026-11-25. Line numbers are for the files as they were that day.

How it fits together

index.html
The content: ⚙️ panel, five sections of tiles. Loads one stylesheet in the head and two scripts at the end of the body. body[data-style] picks the look.
css/index.css
Shared look, then one block per style. Every style rule starts with [data-style="…"].
js/style-switcher.js
Gear opens the panel. A style button changes data-style, which tile-colors watches.
js/nursery-order.js
Counts Nursery clicks and moves the most opened tiles first.
js/masonry.js
Builds the Cusco-style wall for the Polygonal style.
js/bauhaus.js
Builds a ship of blocks per section for the Bauhaus style.
js/bauhaus-edit.js
Drag and reshape the blocks; saves on the device.
js/tile-colors.js
Map colouring for every style; rebuilds on changes.
js/arrange.js
Drag to reorder within a category.
js/favorites.js
Hearts on tiles.
This device only
index-style: chosen style.
nursery-clicks: click counts.
index-ship-v1: your Bauhaus arrangement.
index-order: your order.
index-favs: hearts.
No server and no database.

Adding a style

Add a button with data-style="name" to the panel, then a block of [data-style="name"] rules in the stylesheet. Without a palette in tile-colors.js, it uses the bright one.
