🧾 foods.html — summary

The food list page. Shows every food with its place (fridge, pantry, freezer, other), kind, category, fridge days and notes. Saves to the Family database table wtc_foods. Blanks are allowed. Works on the device when signed out. The main file is foods.html (about 270 lines).

1. How it fits together

Page (foods.html): place tabs, food cards, Save button, Show errors
↕ reads and writes its rows
Device copy: local storage key wtc.foods (each read and write in try/catch)
↕ when signed in
Family database: table wtc_foods (signed-in users only, RLS on)
↑ sign-in is done once, on the Pantry page, under ⚙️ Settings
js/db.js (sign-in, select, insert, patch, timeouts, plain-words errors) and js/config.js (URL and publishable key only)
How to read this: the page keeps its rows in memory. Each change marks a row “not saved yet” and is copied to the device. The Save button sends the unsaved rows to the database, one at a time. A row with no name is not sent. If sending fails, the message goes to the bottom panel, which shows only when “Show errors” is ticked.
