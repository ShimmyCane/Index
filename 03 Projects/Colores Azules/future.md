## Context: night and screen (V2)
- The time band already exists (morning, afternoon, evening, night). Night may need its own blues.
- Screen context: the screen size class only (phone, tablet, desktop), read from the window width. No device ID, no location, no brightness.
- Off by default. Turned on from settings with a toggle. Stored only on the device unless Jimmy agrees otherwise.
- How long the screen has been in use: a session timer on the device. Not stored with the data unless Jimmy asks.

## Colour families (V2)
- One version of the page per colour family, chosen from settings: blues (now), greens, yellows, browns, greys, reds, purples.
- Then the primaries and secondaries together.
- Each family gets its own history and its own taste profile, so one family does not steer another.

## Suggestions from favourites (V2 to V3)
- Start from the favourite blues, not from zero. Ask "which of these other colours would you like?" and show candidates from each family.
- Jimmy picks the ones he likes, and the picks tune the next suggestions.
- Weights: some colours carry more weight than others (a heavy weight for a strong favourite, a light one for a casual pick).

- Reference: colourlovers.com (to be checked: the address and what it does). Jimmy liked it but not its social part. Keep it private and focused on his own taste.
- Each saved group traces Jimmy's preferences over time.
