# Felix Continents — Claude Code pointer

Purpose: a 3-D globe in three.js that Felix can spin, with today's continents and a ⚙️ time slider that takes him back through geological history in animated moments (Pangaea, mountains, volcanoes, drift, oceans, simple climate).

Track: A. Family play

- Design: `schematic.md` (versions V1 to V3, moments, climate, data)
- Q&A history: `convo/` (never compact; start a new version instead)
- AI notes: `04 AI/Felix Continents/brief.md` and `lessons.md`
- Shared conventions: root `CLAUDE.md` (public repo, privacy)

How to run: not built yet. Once built, open `index.html` (no server or build; works from `file://`).

Project rules:
- Public repo. First names only; no photos, school or location details.
- Map data: only open-licence sources, with the source and licence noted in the file that holds it. Check the licence before committing.
- Dates for past moments are approximate, and the page says so.
- Art inspiration from historical artists and traditions only, never a living artist's style.
- No database in V1 unless the convo answers say notes must follow Felix across devices.
