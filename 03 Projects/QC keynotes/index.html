QC keynotes

A first pass over keynotes and general notes on an architectural drawing set. The page checks each keynote against your keynote guideline and marks it green (matches), yellow (questionable) or red (breaks a rule). You then export a marked-up PDF whose marks you can still edit.

🔒 Offline only: the guideline and the drawings stay in this browser. Nothing is uploaded.

1Define the keynote guideline

Type the guideline in. Every field is a rule the scan can test. Leave a field empty when it does not apply. The grey examples are generic, not a standard.

Cloud storage for this guideline
Default: keep local and secure. Choose safe to cloud only for guidelines with no firm or client content. Guidelines are never sent to the database in this version; the choice is recorded in the saved file for later.
Scopes and their scope words Tick the scopes this guideline covers. Scope words are the words an entry must use for that scope (comma separated). A keynote with none of the selected scope words is yellow.
Keynote rows
Each row is: Type, Number, CSI code (four digits, e.g. 02 00), Description. Example: Demo | 1 | 02 00 | Demolish existing roofing assembly down to concrete substrate.
Wording
Exact matches are green. Close ones are yellow and show the closest phrase. Anything else is yellow when the check below is on. Leave empty to skip this.
Rules (drafts until approved) Each rule has a colour, a short description and a full narrative. A draft rule does not run in the scan. Tick Approved to apply it.
General notes: stub. Which note blocks to check and how an unlisted note is coloured will be built later.

4Export the marked-up PDFafter a scan

The export keeps the drawing as it is. Each mark is a separate annotation: green and yellow highlights on keynote entries, red boxes on undefined callouts, and yellow boxes on unreadable pages. Open it in Acrobat, Bluebeam or any viewer and the marks can be moved, changed or deleted.

How to check the export: open it, search for a keynote code (the text is still there), then click a mark. Its comment says why it was coloured.

Nothing you load is saved or sent. Notes for improvement are in ⚙️.
