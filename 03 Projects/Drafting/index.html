How to read this: each line is a line in the file, each shaded area is a solid hatch, and each piece of text is a note. Block uses are expanded at their scale. The drawing is shown as it is read back from the DXF, so a problem in the file shows here. The 3-D view comes in increment 4.

How to read this: each row is one line type in the file, drawn as its dash pattern. A positive number is a dash (pen down), a negative number is a gap (pen up), and 0 is a dot. Numbers are real inches at this scale.

How to read this: each square shows one hatch pattern at real size (2 real inches square), so the spacing you see is the spacing the file will print. Patterns come from the lines stored in the file.
