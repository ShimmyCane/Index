index.html: Shimmy Specs

Summary of index.html (29 lines). Adjacent files: css/app.css, and the scripts in js/. Generated by hand for the MVP.

1. Architecture

One page shell. Scripts load in order; each one adds to the shared window.SS namespace. The screens are built as HTML strings and re-rendered on every change.

index.htmlEmpty #app, error panel #errors, script tags.
→
data.bundle.jsAll data in one script, for file://.
→
engine (no DOM)template, recommend, draft, decisions, flags, import, outputs, store, data.
→
screens.jsHTML for each page.
→
app.jsRouter, nav, ⚙️ drawer, error panel, event handlers.

3. Variables in the adjacent stylesheet (css/app.css)

Colors are tokens on :root (lines 2–18). Dark values are repeated for the system dark setting and for data-theme="dark". Change a token once and every page follows.

TokenDefaultUsed forHow to tweak
--paper#fbfaf7Page backgroundWarmer or cooler paper. Keep it light for printing.
--panel#fffCards, tables, drawer, draftMake it slightly off-white to separate it from the paper.
--ink#1f2328Body textKeep high contrast against --panel.
--muted#6b7280Hints, reasons, notesLighten only if it still passes contrast.
--rule#d9d6cfBorders and dividersDarker for a sharper look.
--gray#eef0f3Hover, nav highlight, neutral badges—
--accent#2f4b6eHeadings, primary buttons, book marksThe one accent color. Keep to one.
--part1, --part1-ink#e7edf5 / #2f4b6ePart 1 tint (wayfinding)Only for the Part 1 gutter.
--part2, --part2-ink#e8f0e6 / #3c5a36Bracket-choice chips in the draftThe chip color tells you where a choice sits.
--part3, --part3-ink#f5efe2 / #6b5420Part 3 tint—
--auto, --review, --decision (+ -ink)blue-gray / amber / redFlag levels: auto, review, decisionKeep the three distinct; they carry meaning.
--div01 … --div00light tintsLeft edge of division rows in the Sections tableOne tone per division group.

--sanssystem UIEverything else—

Sizes and layout are in plain rules, not variables: the nav is 220px wide (.layout), the right panel 340px (.ws-cols), the ⚙️ button 56px (.gear), and the breakpoint for phone width is 900px (end of the file).
