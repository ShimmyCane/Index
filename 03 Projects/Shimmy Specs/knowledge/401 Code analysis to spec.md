# Chapter 401 — Code analysis to spec

Written in our own words. Points marked verify still need checking against a current CSI publication.

## 1. What a CCS can do

- Pick the right **method** (descriptive, performance, reference standard, proprietary) for each requirement and say why.
- **Research and evaluate products**: compare data sheets, test reports, listings, warranties, track record, availability, cost.
- **Read reference standards** fully: know the options a standard leaves to the specifier (type, grade, class) and choose them.
- **Turn the code analysis into requirements**: fire ratings, listed assemblies, flame spread, energy, accessibility.
- **Coordinate** the whole book with the drawings and the consultants' sections.
- **Manage change** in CA: substitutions, submittals, RFIs, ASIs.
- **Manage risk**: allocate responsibility clearly; avoid over- and under-specifying.
- **Maintain masters**: build lessons into the office master.

## 2. Code analysis → spec requirements

| Code fact | Spec consequences (examples) |
|---|---|
| **Construction type** (IBC Ch. 6) | Types I–II: noncombustible; wood limited to allowed uses (e.g. fire-retardant-treated where permitted, blocking, nailers) **(verify IBC 603 for edition)**. Types III–V: Division 06 framing sections likely. |
| **Fire-resistance ratings** | Tested assemblies (UL or similar) named in sections or on drawings; `07 81 00` fireproofing; `07 84 00` firestopping; rated doors `08 11 13` + `08 71 00` labels; rated glazing `08 80 00`. |
| **Sprinklered or not** | Affects allowances (opening protection, finishes); `21 13 13` in the book. |
| **Occupancy** | Finish flame-spread classes (`09`), hardware (egress, panic), accessibility (`10`, `08 71 00`). |
| **Energy code / climate zone** | Insulation R-values `07 21 00`; air barrier `07 27 00` and testing; fenestration U-factor/SHGC `08`. |
| **Exterior wall rules** (e.g. combustible components in Types I–IV) | NFPA 285-tested assemblies; WRB and insulation choices limited **(verify edition)**. |
| **Existing building code** (IEBC) | Level of alteration sets what must be upgraded; repair vs. alteration. |
