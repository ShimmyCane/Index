# Chinese Character Sudoku（汉字数独）— Convo v0.1

**项目：** Chinese Character Sudoku
**轮次：** 第 1 轮澄清问题（由 `/start-project` 开始）

请直接在每个问题下面作答。不确定的可以先空着。

## 我目前的理解

- 卡片 A（2×2）：左列是「爸 / 妈」，右列空白。比如填「爸 / 妈」→ 每行「爸爸」「妈妈」，每列「爸妈」「爸妈」都是词。
- 卡片 B（3×3，2级）：
  ```
  阳 ・ ・
  白 雪 ・
  蝴 ・ 飞
  ```
  （卡片背面透过来的「回」「来」我当作不是题目的一部分。）
- 目标：用孩子最近学过的字，把空格填上，让每一行、每一列的字词都有意义。
- 2×2 最简单，3×3 以上开始难。
- 每个格子可以点，点了从「字库」里选字。右下角 ⚙️ 调难度。

## 规则

1. 「每一行、每一列」是要整行/整列读成一个词（或短语），还是只要**相邻的两个字**能组成词就算对？
   比如卡片 B 第一列「阳 / 白 / 蝴」整列读不成词，所以我猜是另一种规则。卡片 B 的标准答案是什么？能告诉我吗？
2. 读的方向：行只从左往右、列只从上往下？还是反着读也算？
3. 同一个字可以在一题里出现两次吗？（比如「爸爸」「妈妈」）还是像数独一样每行每列不能重复？
4. 一题只有一个标准答案，还是只要组成的都是真词就算对（可能有好几个答案）？

## 判断对错

5. 游戏怎么知道一个词「有道理」？
   - a) 用一份词表（我们事先写好的词），在词表里才算对
   - b) 不自动判断，让家长看一眼再按「对了 ⭐」
   - c) 两者都有：词表里的词自动打勾，词表外的词交给家长确认
6. 填错的时候要怎么提示？（马上变红、按「检查」才显示、或者完全不提示）

## 字和题目从哪里来

7. 「最近教课的字」怎么放进游戏？
   - a) 在 ⚙️ 里有一个框，家长直接打字/粘贴
   - b) 我先帮你写好一份字/词表，以后你告诉我新的字我再加
   - c) 两种都要
8. 能先给我一份现在正在学的字或词（10–30 个就够），让我拿来做第一批题目吗？
9. 题目要：
   - a) 游戏根据词表**自动生成**
   - b) 家长**手动出题**（照着卡片排好哪些格子有字）
   - c) 先放几张跟实体卡片一样的题，再慢慢加自动生成
10. 字库（下面可以选的字）里要不要放几个**干扰字**（不是答案的字）？难度越高放越多？

## 难度（⚙️ 设置）

11. 难度只靠格子大小（2×2 → 3×3 → 4×4）就好，还是还要调：空格数量、干扰字数量、有没有提示？
12. 最大要到几乘几？4×4 够吗？

## 孩子和画面

13. 孩子几岁？认识多少字？会自己看拼音吗？
14. 字上面要不要显示**拼音**？（可以在 ⚙️ 里开关）
15. 点一个字要不要**读出来**（用 iPad 自带的中文发音）？
16. 简体还是繁体？（卡片是简体）
17. 画面要像卡片那样（蓝天、草地、蝴蝶、小鸭子），还是你习惯的粉彩风格就好？
18. 完成一题时要什么奖励？（音效、星星、小动画、记录完成了几题）

## 范围和保存

19. MVP 最小版本，我的建议是：
    - 2×2 和 3×3 两种
    - 点格子 → 从字库选字 → 可以「撤销」
    - 一份写好的词表，自动检查每行每列
    - 右下角 ⚙️：难度、拼音开关、显示错误
    这样可以吗？有什么要加或删的？
20. 需要记住进度吗（比如做过哪些题）？只存在这台 iPad 上就够，还是要多台设备同步？
21. 会不止一个孩子玩吗？需要分开记录吗？
